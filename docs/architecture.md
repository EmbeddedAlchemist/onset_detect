# 架构（已定稿）

> 目标平台：16 kHz / 16 bit 输入，240 MHz RV32（20% 算力份额 = 48 M cycles/s），
> RAM ≤ 20 KB（实际 ≈ 11 KB），不允许前瞻，少缓存 PCM。
> 原型是 Python，但**运行时路径按定点 C 的语义逐条实现**（见 `fxp.py`）。

## 1. 信号链

```
int16 PCM @16 kHz, block 64~256
        │
        ├── 环形缓冲 1280 点 int16 = 2.5 KB  (win 1024 + hop 256，见 §4)
        │
        └── 每 16 ms: 1024 点 Hann(Q15)
                 → Q15 实数 FFT（block-floating-point）
                 → |X|^2 (int64)
                 → log2 Q8.8  → 10 个子带能量
                 → 子带 dB-flux（带内 ±1 bin max）
                 → 直方图分位阈值 + hysteresis + 最小 IOI + ±1 帧局部极大
                 → Event
```

**P0 已实现**：以上全部。
**P3 将插入**：flux 之前的因果 HPSS 谐波抑制（`H = max(X, H - (H>>5))`，`P = max(0, X - αH)`），
这是抑制"贝斯掩蔽 / 侧链恢复"的核心手段。
**P3/P4 将追加**：判别特征（A1 子带重心比、B 衰减斜率、C 时域 click 同步、D 部分集 L1）与 Q4.12 线性打分。

## 2. 为什么这些设计

| 设计 | 收益 | 代价 |
|---|---|---|
| dB 域（log2 Q8.8）flux | 对绝对增益不变 → 响贝斯不会稀释 kick 的增量 | 无（log2 用 CLZ+LUT） |
| 10 个子带而非 0–300 Hz 全带求和 | 避免贝斯谐波 bin 稀释 kick；保留跨带同步信息 | 10 次 log2/帧 |
| block-floating-point FFT | 相比 CMSIS 逐级固定 1/2，保留 ~10 bit 有效位 | 每级一次 max 扫描 |
| 直方图分位阈值 | 自适应响度，O(1) 更新、无排序、无除法 | 16 桶 ⇒ 阈值量化 1.5 dB |
| `win+hop` 环形缓冲 | 单生产者/单消费者、零拷贝、零锁、无额外延迟 | 多占 512 B |
| 判别用"延迟决策 + 特征环" | PCM 环不随确认延迟增长 | 待决事件队列 ≈ 500 B |

## 3. 关键参数（`params.py`）

```
sr=16000  win=1024  hop=256            # 62.5 帧/秒
thr_q_num/thr_q_den = 1/2              # 分位 = 中位数
thr_delta_q88 = 176                    # +4.1 dB
hysteresis 3/5, min_ioi = 45 ms, peak_lookahead = 1 帧
hist: 16 桶 x shift 5 (1.5 dB/桶), decay 2048
```

## 5. 移植到 C 时的必读点

1. **BFP 补偿符号**：`X_int = X_true * 2^-(shift-1)`，所以对数域要 **加** `(shift-1)`。
   写成 `-shift` 会让不同帧的数值不可比（已由 `test_rfft_bias_stable_across_levels` 锁死）。
2. **log2**：`31 - __builtin_clz(x)` 取指数，尾数取 12 bit，16 段 LUT + 8 bit 线性插值（带四舍五入）。
   实测最大误差 0.0044 oct = 0.038 dB。
3. **禁止 int64 乘法进热循环**：`|re|^2+|im|^2` 用 32×32→64（RV32IM 的 `mulh`/M3 的 `SMULL`，2-3 cycles）；
   累加器可用 int64（只有加法）。
4. **无除法**：阈值/特征全部在 log 域做减法；`hysteresis` 用 `(thr*3)/5` 的编译期常量。
5. **环形缓冲必须是 win+hop**，否则 ISR 会覆写当前窗最旧的 hop 个样本。
6. **FFT 任务不放在音频中断里**：1024 点 ≈ 270 µs @240 MHz，要放到任务，靠 `block_done` 标志驱动。
7. 只读表（twiddle/Hann/LUT）建议拷到 RAM，规避 flash wait-state 造成的抖动。

## 6. 已知限制（P1/P2 处理）

1. **时间戳偏差**：P0 用帧中心 `k*hop + win/2`，Hann(1024) 的 flux 峰相对真实起振滞后 ~16-24 ms，
   需在 P1 用标注标定一个常数偏差并减去（后续再加时域包络的亚帧精修）。
2. **阈值为平线**：直方图中位数为 0（多数帧 flux=0），`thr = delta` 恒为 4.1 dB，
   导致基线在每秒 20+ 次触发。P2 改用更高的分位（q80/q90）+ 相对峰值门限。
3. **无 HPSS / 无判别**：贝斯、侧链恢复、军鼓体会全部被当作打击（P3/P4 解决）。
